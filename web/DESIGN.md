# Siaga product page

The first viewport pairs the offline claim with a rendered Act screen. Its status bar, emergency brief, guide excerpt and Call 112 control are part of a static illustration. Only the navigation and text links are interactive.

The page uses the local system font, alternating white and light gray fields, and a black privacy section. The dark appearance uses black and charcoal. Blue identifies links, orange marks high severity, and red marks Call 112. The sticky navigation is the only blurred surface. The tool list animates once on entry when motion is enabled.

## Finish review

Verdict: ready. Chrome measured no horizontal overflow at 360, 375 and 1440 pixels. The mobile review prompted a smaller mockup and tighter spacing so the complete Call 112 control fits within the 812-pixel first viewport. The page loaded from disk without remote requests.
